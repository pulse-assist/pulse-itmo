# my.itmo — плагин «Пульса»

Личное расписание из my.itmo.ru в «Пульсе»: вход через ITMO.ID в браузере владельца, неделя по дням (на
телефоне — день за днём), команды для агентов.

- **Страница** «Расписание ИТМО» (меню «Плагины ▾», можно закрепить): неделя, соседние недели, «Сегодня»,
  брони аудиторий и физкультура — переключателем.
- **Агентам:** `pulse itmo today`, `pulse itmo schedule --from ГГГГ-ММ-ДД --to ГГГГ-ММ-ДД [--all]`,
  `pulse itmo status`; скилл «Расписание ИТМО».
- **Вход.** Владелец открывает id.itmo.ru по ссылке плагина и входит сам — пароль плагин не видит. После входа
  браузер открывает my.itmo.ru; адрес этой страницы (с кодом) владелец вставляет на страницу плагина, и плагин
  меняет код на токены (OIDC, PKCE, клиент `student-personal-cabinet`). Refresh token (30 дней) меняется при
  каждом продлении и хранится в служебной папке плагина (`state.json`, права 0600). Продлить не удалось —
  сигнал «Войдите в ITMO.ID снова».

Установка в Пульс: «Поставь плагин <ссылка на репозиторий или архив>» в чате — дальше агент идёт по
[INSTALL.md](INSTALL.md). Разработка — [AGENTS.md](AGENTS.md).

## Источники

Протокол ITMO.ID и ручки расписания — по открытым проектам (MIT):

- [alllexey-dev/itmo-mcp](https://github.com/alllexey-dev/itmo-mcp) — исследование ITMO.ID (`research/auth.md`) и
  расписания (`research/services/schedule.md`), клиент `src/auth/itmo-id.ts`: PKCE, обмен кода, refresh.
- [iburakov/my-itmo-ru-to-ical](https://github.com/iburakov/my-itmo-ru-to-ical) — `GET /api/schedule/schedule/personal`.

API my.itmo.ru неофициальный и может меняться без предупреждения.
