# Установка плагина «my.itmo»

Инструкция для агента Пульса после `pulse plugins install …`. Пройди её целиком.

## 1. Проверь, что плагин запустился

```bash
pulse plugins list            # у itmo — status: running
pulse itmo status             # logged_in: false — так и должно быть до входа
```

Если status: error — `pulse plugins logs itmo --lines 80`, расскажи владельцу, что в журнале, и остановись.

## 2. Закрепи страницу

```bash
pulse plugins pin itmo schedule
```

## 3. Вход — делает владелец сам

Пароль ITMO.ID вводит только владелец, на id.itmo.ru, в своём браузере. Не проси у него пароль, логин или
коды и не пытайся войти сам. Скажи владельцу:

> Откройте «Расписание ИТМО» в меню (или [по ссылке](/p/itmo/schedule)), нажмите «Открыть id.itmo.ru» и войдите.
> Браузер откроет my.itmo.ru — скопируйте адрес из адресной строки и в течение минуты вставьте его на странице плагина.

## 4. Проверь после входа владельца

```bash
pulse itmo status             # logged_in: true, user — имя и номер ИСУ
pulse itmo today              # пары на сегодня (пустой список — пар нет)
```

## 5. Расскажи владельцу

Что установлен «my.itmo» (версия), страница «Расписание ИТМО» закреплена в меню, агенты отвечают на вопросы о
парах (`pulse itmo today`, `pulse itmo schedule`), вход продлевается сам; если не пользоваться больше 30 дней —
придёт сигнал «Войдите в ITMO.ID снова».
